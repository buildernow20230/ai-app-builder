# ai-app-builder

منصة عربية لبناء التطبيقات والمواقع بالذكاء الاصطناعي. المستخدم يوصف التطبيق بالعربي، والمنصة تولّده بواجهة عربية (RTL) وتعرض له معاينة مباشرة.

## الحالة الحالية (MVP — المرحلة الأولى)

- **apps/api**: خادم Node.js/TypeScript (Fastify) فيه:
  - `GET /health`: فحص الحالة
  - `GET /domains`: المجالات المدعومة (المخزون والمبيعات، الحسابات)
  - `POST /generate`: يولّد تطبيق HTML كامل بالعربي عن طريق Anthropic API، ويرجع الاستهلاك بالتوكنز عشان حساب التكلفة والهامش
- **apps/web**: واجهة React عربية فيها مربع الوصف ومعاينة التطبيق المولَّد في iframe معزول

## التشغيل محليًا

المتطلبات: Node.js 22 أو أحدث.

```bash
npm install
cp .env.example .env   # وضيف ANTHROPIC_API_KEY
npm run dev:api        # الخادم على http://localhost:3001
npm run dev:web        # الواجهة على http://localhost:5173
```

## الخطوات الجاية

1. حسابات المستخدمين وتسجيل الدخول
2. حفظ المشاريع وتعديل التطبيق بالمحادثة (تعديلات متتالية بدل التوليد من الصفر)
3. تسجيل الاستهلاك في قاعدة بيانات وحساب السعر بالهامش
4. الرصيد والدفع عن طريق Xpay
5. Sandbox مُدار لتشغيل تطبيقات فيها خادم وقاعدة بيانات، والنشر على رابط
